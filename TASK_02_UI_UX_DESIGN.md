# DP-FCFS Project
## Task 02 – UI/UX Design

# Objective

Design the complete frontend interface for the Dynamic Predictive FCFS (DP-FCFS) system.

This task focuses ONLY on the user interface and user experience.

No backend logic, API calls, FCFS scheduling, prediction algorithms, or database integration should be implemented.

The result should be a modern, professional, responsive dashboard similar to enterprise cloud platforms such as AWS, Azure, or Google Cloud.
